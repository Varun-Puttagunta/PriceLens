Does the model actually work?

Every one of the 36 listings is re-priced here, live, using only sales that had already closed on the day it went on the market. The model never sees the property's own outcome, and never sees a comp from its future. These are the errors that produces.

      What changed when the firm started using it

      The tool went live eight months into the engagement. Before that, asking prices were set the usual way — a walk-through, a handful of comps, a round number. These are the two halves of the same book, in the same market, with the same agents.
